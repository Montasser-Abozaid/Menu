# منيو سماش برجر — منيو رقمي بالطلب عبر واتساب

منيو رقمي ثنائي اللغة (عربي / إنجليزي) لمطعم سماش برجر، بدون أي مكتبات أو خادم: ملفات HTML وCSS وJavaScript فقط.

## المزايا
- 8 أقسام بـ 4 أصناف في كل قسم (32 صنفًا) مع بحث وتنقل بين الأقسام.
- سلة طلبات وإضافات وأحجام، وإرسال الطلب جاهزًا عبر واتساب.
- أنواع الطلب: توصيل، استلام، داخل المطعم.
- وضع داكن وفاتح، وتبديل اللغة، وتصميم متجاوب مع الجوال.
- خريطة المطعم وزر الاتجاهات، وحالة الفتح والإغلاق بحسب مواعيد العمل.
- خط Expo Arabic.

## هيكل المشروع
```
index.html          الصفحة الرئيسية
css/style.css       التصميم
js/config.js        إعدادات المطعم (الاسم، واتساب، العنوان، الخريطة، العملة، المواعيد)
js/menu.js          الأقسام والأصناف والأسعار والإضافات
js/app.js           منطق المنيو والسلة
assets/img/menu/    صور الأصناف (pN.jpg)
assets/img/hero-*.jpg  خلفيات الهيرو (ديسكتوب وموبايل)
assets/fonts/       خطوط Expo Arabic
```

## التعديل
- **بيانات المطعم:** عدّل `js/config.js`.
- **الأصناف والأسعار:** عدّل `js/menu.js`، وكل صنف له `id` و`cat` و`ar` و`en` و`price` و`img`.
- **روابط التواصل:** `facebook` و`instagram` في `js/config.js` (اتركها فارغة لإخفاء الزر).
- **صورة صنف:** ضع الصورة في `assets/img/menu/` وغيّر مسارها في `img`.

## التشغيل محليًا
افتح `index.html` في المتصفح، أو شغّل خادمًا بسيطًا:
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر
ارفع محتوى المجلد كما هو على أي استضافة ملفات ثابتة (cPanel / Hostinger / GitHub Pages / Netlify).

## ملاحظات
- أسعار الأصناف وأرقام الدفع (فودافون كاش وإنستا باي) قيم تجريبية، بدّلها ببيانات المطعم.
- صور بعض الأصناف المضافة (بيكون برجر، دجاج بالجبن، دجاج بالكريمة، بطاطس بالجبنة، لاتيه، براوني، تشيز كيك لوتس) مؤقتة، وهي نسخ من صور أصناف مشابهة، فاستبدلها بصور حقيقية.
- العملة والمنطقة الزمنية في `js/config.js` ما زالتا الجنيه المصري وتوقيت القاهرة.
